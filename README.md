# Interactive Venue Ticketing System

## Web & Mobile I 

This project is an interactive front-end ticket selection website based on a real auditorium located in ADA University's C Building.

### Venue Information (I counted it 1 by 1)

- Venue name: ADA University C Building Auditorium
- Venue type: Auditorium
- Total capacity: 267 seats
- Seating sections: 7 (6 main blocks and 1 second-floor section)
- Seating rows: 9 (3 lower, 5 upper, and 1 second-floor row)
- Second floor: 1 row with 15 seats
- Technologies i will use: HTML, CSS, JavaScript

### Seating Structure

| Section | Seats per row | Total|
|---|---|---|
| Lower Left | 7, 8, 8 | 23 |
| Lower Center | 10, 11, 12 | 33 |
| Lower Right | 7, 8, 8 | 23 |
| Upper Left | 8, 10, 9, 9, 8 | 44 |
| Upper Center | 15, 16, 17, 18, 19 | 85 |
| Upper Right | 8, 10, 9, 9, 8 | 44 |
| Second floor | 15 | 15 |
| **Total** | | **267** |

### Planned Functionality

- Dynamically generated seating map
- Interactive seat inspection
- Available, inspected, in-cart and unavailable seat states
- Ticket categories and pricing
- Zoom and directional map navigation
- Add-to-cart and ticket removal
- Total price calculation
- Cart persistence using localStorage
- Responsive desktop and mobile interface

### Development Plan

**Week 1:** Venue analysis, seating design, HTML/CSS structure and JavaScript venue model.

**Week 2:** Dynamic seat generation and inspection.

**Week 3:** Map navigation, shopping cart and localStorage.

**Week 4:** Responsive design, testing, improvements and optional mouse navigation.
